# ไฟล์ตัวอย่าง (ข้อมูลสมมติ)

ไฟล์ในโฟลเดอร์นี้**เป็นข้อมูลที่แต่งขึ้นทั้งหมด** ทั้งเลขหมาย IMSI IMEI และชื่อเสา ไม่ได้มาจาก CDR จริง
ไฟล์เหล่านี้ใช้รูปแบบเดียวกับไฟล์ที่ผู้ให้บริการส่งให้ทุกอย่าง ทั้งชื่อคอลัมน์และชื่อชีต จึงใช้ทดสอบการนำเข้าและสาธิตแอปได้

| ไฟล์ | รูปแบบ | สถานการณ์ที่ใส่ไว้ |
| --- | --- | --- |
| `sample-ais-0810000101.xlsx` | AIS (ชีตเดียว) | เปลี่ยนเครื่องแล้วใช้เครื่อง 2 ซิม, เลขเมียนมาที่มี prefix `69710`, ช่วงเงียบ 3 วัน, การติดต่อทอดผ่าน 0860000111, โทรถี่คืนวันที่ 5 ส.ค. พร้อมกับเป้าหมาย B |
| `sample-ais-0820000202.xlsx` | AIS (ชีตเดียว) | ผู้ติดต่อร่วมกับอีกสองเป้าหมาย, โทรหาเป้าหมาย C โดยตรง, โทรถี่กลางดึก, เดินทางเข้ากรุงเทพฯ |
| `sample-dtac-0630000303.xlsx` | True/DTAC (Info + VOICE/IMS/SMS/DATA/WIFI) | คู่สายในเครือข่ายเดียวกัน (มีบันทึกทั้ง ORIG และ TERM), สายเดียวกันที่ถูกบันทึกซ้ำทั้งในชีต VOICE และ IMS (รวมถึงสายที่ไม่สำเร็จซึ่ง VOICE บันทึกช้ากว่าหลายวินาที), สายที่ไม่สำเร็จ, เลขมาเลเซีย, เส้นทางมีพิกัดไปกรุงเทพฯ และพบกับ B, คู่สายที่ใช้เครื่องเก่าของ A |

ไฟล์ทั้งสามสร้างจาก `src/lib/samples/generate.ts` ซึ่งเป็นตัวสร้างเดียวกับที่ใช้กับปุ่ม "ใช้ข้อมูลตัวอย่าง" ในแอป
ถ้าแก้ตัวสร้าง ให้สร้างไฟล์ใหม่ด้วยคำสั่ง:

```bash
npm run make:samples
```

> **ห้ามนำไฟล์ CDR จริงมาไว้ใน repository นี้** เพราะ repository เป็นสาธารณะ
> `.gitignore` จึงกันไฟล์ `.xlsx`/`.csv` ทุกที่ ยกเว้นโฟลเดอร์นี้
